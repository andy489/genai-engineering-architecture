# Scaling and Optimizing GenAI Performance

## Running the Demo

Install `uv` following the instructions on [https://docs.astral.sh/uv/#installation](https://docs.astral.sh/uv/#installation), then run:

```bash
uv run bottleneck_demo.py
```

Alternatively, install dependencies using pip (in a virtual environment) and run with Python:

```bash
pip install -r requirements.txt
python bottleneck_demo.py
```
